## 👋 Sobre mim

Sou o **Giovanne**, Analista de Dados Pleno no **Grupo Mérito** e estudante de **Ciência da Computação na UNIP**, em São Paulo.
Construo sistemas de dados do zero: da ingestão e modelagem até o dashboard e a automação que entregam o resultado para quem precisa tomar decisão.

No dia a dia trabalho com pipelines ETL, data warehouse em Azure, agentes de IA integrados ao WhatsApp para qualificação de leads e agendamento de visitas, relatórios automáticos para times de vendas e modelos de forecasting de receita, sempre com integrações via APIs REST e Webhooks.

**Interesses:** engenharia de dados · BI · automação · agentes de IA · IoT e Machine Learning
